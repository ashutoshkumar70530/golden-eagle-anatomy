# Golden Eagle Anatomy

An interactive, beginner-friendly learning experience about the external anatomy of the Golden Eagle (*Aquila chrysaetos*), developed under **Ashutosh Kumar E-Learning**.

## Project status

**Planning and technical setup.** Course content, final graphics, and production code have not yet been created.

## Planned deliverables

1. **Public portfolio demo** — a browser-based experience with a short project introduction.
2. **SCORM 1.2 package** — a separate LMS-ready course package for completion and score reporting.

The public demo and SCORM package are separate outputs and will be tested separately.

## Repository map

- `docs/` — project brief, technical plan, science references, and QA checklist.
- `src/` — approved custom HTML/CSS/JavaScript components, if needed.
- `assets/` — only assets permitted for public redistribution.
- `licenses/` — asset credits, license evidence, and restrictions.
- `web-demo/` — public demo wrapper and published web output, once approved.
- `scorm/` — SCORM packaging and LMS testing notes; do not assume a SCORM ZIP is a public web demo.

## Important safeguards

- Do not commit passwords, tokens, learner data, or private information.
- Do not upload the Storyline authoring file or any media unless public redistribution is intended and permitted.
- Record attribution and license terms for every third-party asset.
- Scientific accuracy and asset licensing are release gates.
- Do not claim WCAG conformance until the applicable checks have been completed.

## Current technical direction

Author in Articulate Storyline 360 on Windows. Test a **Publish to Web** output for the public demo and a separate **SCORM 1.2** output for LMS delivery. Confirm hosting compatibility with a small test before choosing the final deployment approach.

See [Technical Plan](docs/TECHNICAL-PLAN.md) and [Testing Checklist](docs/TESTING-CHECKLIST.md).
