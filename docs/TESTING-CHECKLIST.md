# Testing Checklist

Status: **Draft for user review**  
Use this checklist for the public web demo and SCORM package separately. Passing selected checks does not by itself establish full WCAG conformance.

## A. Public web demo

- [ ] Project introduction and launch link work.
- [ ] Hosted Storyline launch page opens successfully.
- [ ] All slides, images, audio, video, fonts, and interactions load.
- [ ] No broken file paths or missing assets.
- [ ] Navigation and branching behave as intended.
- [ ] Browser refresh/relaunch behavior is understood and documented.
- [ ] Tested in current desktop Chrome and Edge; record versions and results.
- [ ] Keyboard-only navigation works for essential interactions.
- [ ] Focus is visible and follows a logical order.
- [ ] Text contrast and text size are readable.
- [ ] Essential information is not conveyed by color or audio alone.
- [ ] Alternative text or accessible alternatives are provided where needed.
- [ ] Custom code, if any, has been tested for errors and keyboard access.

## B. SCORM 1.2 package

- [ ] ZIP is published from Storyline's LMS/LRS option with SCORM 1.2 selected.
- [ ] Package imports and launches in a SCORM test environment.
- [ ] Completion status is reported correctly.
- [ ] Final score is reported correctly.
- [ ] Pass threshold is configured consistently with the approved assessment.
- [ ] Closing and relaunching resumes as intended.
- [ ] Progress, score, and unlocked mission state behave as intended after resume.
- [ ] Retry behavior and best-score rules are verified.
- [ ] Final results and LMS status remain consistent after relaunch.
- [ ] Target LMS is tested once selected.

## C. Learning and science

- [ ] Every objective is covered by learning content and assessment.
- [ ] Golden Eagle-specific terminology is verified.
- [ ] Structure/function explanations are supported by reliable sources.
- [ ] Similar-looking structures are distinguished accurately.
- [ ] Visual callouts point to the correct anatomical structures.
- [ ] Skeletal content stays within the agreed supporting scope.
- [ ] Final assessment has 8–10 questions and the approved 70% pass threshold.
- [ ] Feedback is accurate, useful, and consistent.

## D. Licensing and release

- [ ] Every external asset has a recorded source and license.
- [ ] License terms permit public redistribution and the intended use.
- [ ] Attribution is included where required.
- [ ] No restricted, confidential, or personal data is committed.
- [ ] Storyline source project and SCORM ZIP are excluded unless intentionally approved.
- [ ] Repository contains no credentials, API keys, or tokens.
- [ ] Final release notes identify the tested build and known limitations.
