# Golden Eagle Anatomy — Visual Asset Register v0.1

**Status:** Production planning / sourcing specification  
**Owner:** Ashutosh Kumar E-Learning  
**Rule:** No asset is cleared for public release until its exact source, creator, license, attribution requirements, modification rights, and redistribution permission are recorded and reviewed.

## Asset principles

1. Use verified Golden Eagle (*Aquila chrysaetos*) photographs for species-specific recognition.
2. Use generated art only for atmospheric or decorative scenes—not as evidence for precise anatomy, feather placement, skeletal alignment, or species-specific morphology.
3. Never add anatomical labels to an image until the exact feature is confirmed by a qualified source/reviewer.
4. Avoid assets that imply all Golden Eagles have identical plumage. Juvenile and adult plumage can differ, and white wing/tail patches vary.
5. Public portfolio files must not contain images with unclear licensing. If a source permits viewing but not redistribution, link to it rather than copying the file.
6. Keep source files, attribution, crop notes, and any permission correspondence in the asset register.

## File naming convention

Use `V##_short-description_source-or-creator_license.ext`, for example:
`V03_golden-eagle-head_CreatorName_CC-BY-4.0.jpg`

Do not use the example name until a real asset and license have been verified.

## Production decision

Start with V03, V05, V09, and V02 because the three missions depend on reliable head, wing, and foot imagery. Do not finalize hotspot positions or label placement until the actual chosen assets are available and reviewed.
