## License notes

- **Public Domain:** USFWS pages above explicitly identify the listed media as Public Domain. Keep source URL and the page's credit information in the course credits and asset manifest.
- **CC BY 4.0:** Credit creator, link the license, indicate if changes were made, and do not imply endorsement.
- **CC BY-SA:** Provide attribution, link the license, indicate modifications, and check share-alike requirements for adaptations. If a crop/annotated adaptation is made, retain a record of the exact license version and review compatibility with the planned public distribution.
- **Wikimedia category pages:** Use them only to discover individual files. Each selected file needs its own page-level license review.
